# Using Marvnor Truth-Preserving Model System

Marvnor works alongside an existing LLM application; you do not need to replace the main model.

1. Open the [Marvnor user portal](https://marvnor.com), then register and sign in.
2. Create an SDK key in the console and save it immediately; the full key is shown only once.
3. Start with a question whose answer you can verify. Following the console integration example, send the question and relevant evidence to Marvnor.
4. Read the [six results](INTRODUCTION.md), then decide whether the model should answer, ask for more information, or hand the case to a human reviewer. The application may also ignore the handling signal and choose its own next step.
