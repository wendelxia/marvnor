# Marvnor

大模型写答案很快。答得顺，不代表有依据；资料不够或互相矛盾时，答案也可能显得很肯定。

Marvnor 是配合大模型使用的工具。它帮应用检查关键结论有没有足够依据、资料之间有没有矛盾。模型照常读资料、写回答；什么时候继续、补资料或请人复核，仍由应用和使用者决定。

可以先从企业问答、研究资料整理或业务流程里的一个具体问题试起。选能找到原始资料、也能核对结果的题目，看看它能否减少没有依据却说得很肯定的回答。
