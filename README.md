# Marvnor

大模型负责读资料、写答案。Marvnor 帮它核对关键判断，尤其是在资料不足或互相矛盾的时候。

应用把待核对的结论和已整理的信息交给 Marvnor，默认拿回六项结果：**结论、依据类型、是否冲突、原因、处理信号、依据路径**。模型可以据此调整回答；继续、补资料或请人复核，仍由应用和使用者决定。

先拿一个答案能人工核对的问题试试，看模型接入后会不会少说没有依据的肯定话。
