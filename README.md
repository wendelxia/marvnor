# Marvnor

## 回答可以很快，判断需要有边界

大模型能阅读和表达，却不总能判断一个答案是否已有足够依据。Marvnor 是配合大模型使用的辅助服务，帮助 AI 应用在关键结论上识别：可以继续、信息不足，还是需要复核。

它不替代大模型，也不替代业务系统的最终决定。模型负责理解和说明，业务系统负责权限与行动，Marvnor 为中间的判断提供更明确的信号。

适用场景包括企业知识问答、研究资料整理和需要人工复核入口的业务自动化。先从一个有明确问题和可用资料的流程开始，观察它是否减少无依据的确定回答。
