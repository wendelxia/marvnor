# Marvnor

大模型写答案很快。但有些答案不能只看它说得顺不顺，还得看资料够不够、有没有相互矛盾的地方。

Marvnor 是配合大模型使用的工具。它帮应用检查那些需要认真对待的结论，提醒应用什么时候可以继续，什么时候该补资料或请人再看一眼。模型照常读资料、写回答；最终怎么处理，仍由应用和使用者决定。

可以先从企业问答、研究资料整理或业务流程里的一个具体问题试起。选能找到原始资料、也能核对结果的题目，看看它能否减少没有依据却说得很肯定的回答。
