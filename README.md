# Marvnor

让大模型在关键判断上有据可查。

大模型负责理解和表达，Marvnor 是它旁边的计算工具。应用交给它一个待核对的结论和已整理的相关信息，默认拿回六项结果：**结论、依据类型、是否冲突、原因、处理信号、依据路径**。模型可以据此调整回答，应用决定下一步怎么做。

比如，两条已整理的记录对“是否符合退款条件”给出相反结论。Marvnor 可以返回 `UNKNOWN`、`conflict=true` 和 `decision=clarify`，让应用提醒模型先核对冲突，而不是选一边回答。没有依据与依据冲突，也不会被混成同一件事。
