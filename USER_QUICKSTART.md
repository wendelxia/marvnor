# Marvnor Quickstart

[Read the current quickstart](https://api.marvnor.com/docs?lang=en) · [中文版](https://api.marvnor.com/docs?lang=zh-CN)

New account registration and trial access are paused. If you already have an account, [sign in](https://api.marvnor.com/login?lang=en), create or reuse a Key, and add it in your AI's MCP settings.

Inactivity no longer revokes an ordinary Key or removes its saved records. Explicit expiration and revocation still apply.
