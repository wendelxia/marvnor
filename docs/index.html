An order has one payment status. What happens when saved records say both “pending” and “paid”?

  1. 01

    Save a fact

    Store status = pending.

    TRUEPending is supported.
  2. 02

    Add a conflicting record

    Also store status = paid.

    CONFLICTBoth return UNKNOWN. Ask for clarification.
    See the actual response
    {
  "conclusion": "UNKNOWN",
  "conflict": true,
  "reason": "conflicting_values",
  "path": ["paid", "pending"],
  "decision": "needs_review",
  "evidence_kind": "conflict"
}
  3. 03

    Resolve the conflict

    Remove the incorrect “paid” record.

    TRUEPending is supported again. No conflict.
  4. 04

    Correct the remaining fact

    Edit the saved value to paid.

    TRUEPaid is supported. Pending becomes UNKNOWN.
  5. 05

    Delete the demo data

    Remove only this example’s records.
